# Open questions

- **What deploys `frostaura.net`, from which image, and where does its data land?** The host serves this SPA and a live API, and nothing in this repo deploys it (see state). Until the deploying stack is found, nobody knows whether a push to `main` reaches production, where submissions persist, or whether they are backed up. Owner: `unassigned`.
- **SQLite instead of PostgreSQL, with no schema-evolution path and no backup.** Re-verified 2026-10-22: `Microsoft.EntityFrameworkCore.Sqlite` 10.0.5 in `FrostAura.Infrastructure` and the test project, no Npgsql anywhere; the API calls `Database.EnsureCreatedAsync()` at startup (`src/backend/FrostAura.Api/Program.cs:49`) and no `Migrations/` directory exists, although `FrostAura.Api` references `EntityFrameworkCore.Design`. `EnsureCreated` only builds a schema that is absent, so any change to `CareerSubmission` or `InvestorSubmission` either silently skips an existing `frostaura-data` volume or forces destroying it. `docs/architecture/system-components.md` calls SQLite the "first public-site baseline" and never flags it against the mandate. One decision answers both halves — migrate to Postgres with EF migrations, or declare a waiver and a frozen schema — and it was meant to land before the site deployed. The site is now reachable in production (2026-10-22), so the funnels may already be collecting into a schema that cannot evolve. Owner: Dean.
- **No Tailwind, no shadcn/ui, no design system on the brand's front door.** Re-verified 2026-10-22: no `@radix-ui/*` dependency, no `tailwind.config`, no `components.json`; `src/web/src/styles.css` is the only stylesheet. Adopt the mandated stack or record a waiver — the deviation has never been declared either way. Owner: Dean, parent-controlled.
- **The site carries an investor-capital funnel.** Re-verified 2026-10-22: `siteContent.ts` has an investor hero (CTA "Share your investment thesis") and a "selective long-horizon partners" block welcoming "aligned capital", and `InvestorSubmission` stores capital range, horizon, investor type, preferred mode and thesis. It is **reachable in production**: on 2026-10-22 `frostaura.net/api/investors/submissions` answered as a live POST-only route. Whether soliciting outside capital fits the parent capital doctrine is not this scope's call; this scope records only that the mechanism exists. Owner: Dean.
- **What are the success metrics, and what would collect them?** No metric set was ever committed, and no analytics or tag script exists in `src/web/src` or `index.html` (re-searched 2026-10-22). The instrumentation decision has to precede the metric decision. Owner: Dean.
- **Should this memory store live in a public repository?** The division requires each project's context files to be committed to its own repo, and `frostaura/fa.public` is public (`gh repo view`, 2026-10-14) — so the open questions above, the PII-hazard notes and the capital-funnel analysis are published. Either make the repo private, or accept that this store is public writing and keep it to what may be read outside the company. The unpushed context commit (see state) is held by this question: pushing it publishes the store and republishes `:latest`. Owner: Dean, parent-controlled.
